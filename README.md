# Quiet TV

Лёгкий лаунчер для Android TV, управляемый пультом. Закрытый репозиторий готовых выпусков; исходники разрабатываются локально.

## Скачать

Откройте **Releases** и скачайте APK последней версии. SHA-256 указан в файле SHA256SUMS.txt рядом с APK.

## Возможности

- Рабочий стол с избранными приложениями, изменением порядка и горизонтальными рядами.
- Недавние приложения и продолжение просмотра из системной истории совместимых приложений.
- Часы, погода, природные фоны из интернета и локальные фотографии.
- Источники сигнала, уведомления и настройка кнопок пульта.
- Прозрачный хедер и боковая панель настроек.

## Совместимость

Android TV 9 или новее. Проверено на Xiaomi Mi TV 4S / MiTV-MSSP1 с Android 9. Переключение тюнера/HDMI и заряд пульта зависят от прошивки; совместимость с другими телевизорами пока не подтверждена.

## Установка и обновление

Установите APK через файловый менеджер либо ADB:

```sh
adb install -r quiet-tv-0.15.apk
```

Для обновления сохраните данные приложения; APK должен иметь ту же подпись. Выбор домашнего экрана зависит от прошивки. Не отключайте штатный лаунчер, пока не проверили запуск Quiet TV и способ возврата.

## Доступы

Уведомления требуют доступа к уведомлениям, всплывающие карточки — разрешения показа поверх приложений. Назначения кнопок требуют службы специальных возможностей (без чтения содержимого окон). Локальные фоны и история просмотра используют соответствующие разрешения Android. Интернет нужен погоде, фонам и превью; определение города по IP приблизительное. Батарея доступна только для поддерживаемых Bluetooth-пультов.

Фотографии, иконки приложений и содержимое сторонних сервисов принадлежат их правообладателям. В релиз не входят сторонние APK, фоны или личная история просмотра.

## Статус

Ранний рабочий прототип для личного использования. Обновления публикуются после локальной проверки на телевизоре.
